# 3D-модель территории жилого городка АО «НЭПТ»

Этап 1 — **разметка основы** по «Схеме генерального плана» (Civil 3D, лист A2) плюс
парковка с навесами и габионами.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Интерактивный 3D-просмотр (Three.js 0.160, OrbitControls). |
| `data/site.json` | Геометрия площадки в метрах: граница участка, бордюры проездов, пятна застройки с экспликацией, ограждения и ворота, парковка (зоны A/B, места), навес, габионы. |
| `textures/plan.jpg` | Растр схемы генплана (200 dpi), ложится на землю как «чертёж». |

## Запуск

Файлы грузятся через `fetch`, поэтому нужен любой статический сервер:

```bash
cd territory-3d
python3 -m http.server 8000
# открыть http://localhost:8000/
```

Параметры адреса: `?view=top` (вид сверху), `?view=park` (к парковке),
`?cam=x,y,z&at=x,y,z` (произвольная камера, метры).

## Система координат и масштаб

- X — восток (вправо по листу), Y — север (вверх по листу), Z (в three.js) = −Y.
- Начало — юго-западный угол текстуры; участок ≈ 99 × 203 м.
- Масштаб принят по шагу стояночных мест 2,5 м = 12,73 pt → 1 pt = 0,1964 м
  (лист напечатан «по размеру», номинально ≈ 1:557). Если есть точная привязка
  (координаты углов участка), масштаб пересчитывается одной константой `S`
  в скрипте выгрузки.

## Парковка (северная полоса за ограждением, 19 косых мест)

- **Зона A** — места 1–10, ближе к выезду через КПП 10.1: односкатный стальной
  навес (стойки 150×150, высота 2,6 м у ограждения / 3,0 м со стороны проезда,
  кровля — профлист).
- **Зона B** — места 11–19, открытая. Отделена от зоны A габионной стенкой
  1000×600 (толщина 300 мм принята), 8 коробов вдоль линии разметки между
  местами 10 и 11, заполнение — средний камень.

Все параметры (разбивка на зоны, высоты навеса, ярусность габионов) — в
`data/site.json`, просмотрщик читает их напрямую.
