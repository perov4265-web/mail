# 3D-модель территории жилого городка АО «НЭПТ»

Этап 1 — **разметка основы** по «Схеме генерального плана» (Civil 3D, лист A2):
здания, проезды, ограждения, дорожные знаки на стойках, парковка у КПП 10.1 с
навесами и габионами.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Интерактивный 3D-просмотр (Three.js 0.160, OrbitControls). |
| `data/site.json` | Геометрия площадки в метрах: граница участка, бордюры проездов, пятна застройки с экспликацией, ограждения и ворота, парковка (зоны A/B, места), навесы, габионы, дорожные знаки (46 стоек), стрелки движения. |
| `textures/plan.jpg` | Растр схемы генплана (200 dpi) без слоя дорожных знаков (символы, выноски и номера убраны из PDF на уровне операторов), ложится на землю как «чертёж». |
| `js/building.js` | Рендер детальных зданий: стены с проёмами, остекление, двери, мебель, крыльца, плоская кровля с парапетом или двускатная на фермах; постановка на пятно генплана. |
| `data/abk1.json` | АБК-1 (здание 1): 226 стеновых панелей, 33 окна, 30 дверей, мебель, 3 входа — из `Office_Building-1.dwg`. |
| `data/abk2.json` | АБК-2 (здание 2.1, удлинённый V.2): стены, стеклянные перегородки, двери, мебель — оцифровка растрового плана; фасад, кровля, фермы — по «Итог1». |
| `tools/` | Скрипты выгрузки (справочно). |

## Запуск

Файлы грузятся через `fetch`, поэтому нужен любой статический сервер:

```bash
cd territory-3d
python3 -m http.server 8000
# открыть http://localhost:8000/
```

Параметры адреса: `?view=top` (вид сверху), `?view=park` (к парковке),
`?cam=x,y,z&at=x,y,z` (произвольная камера, метры).

## Система координат и масштаб

- X — восток (вправо по листу), Y — север (вверх по листу), Z (в three.js) = −Y.
- Начало — юго-западный угол текстуры; участок ≈ 177 × 365 м.
- Масштаб листа 1:1000 (1 pt = 0,3528 м). Проверен по шагу стояночных мест
  2,5 м, глубине места 5,4 м и ширине проезда 7,8 м на внутренней парковке.

## Парковка у КПП 10.1 (внутри ограждения)

Два ряда перпендикулярных мест (23 северный, 26 южный) вдоль одностороннего
проезда 7,8 м. Делится на две части:

- **Зона A** — 27 мест ближе к выезду (КПП 10.1): односкатные стальные навесы
  с двух сторон проезда, 4 м у проезда и 2 м по дальнему краю, стойки 150×150
  через 2 места, кровля — профлист.
- **Зона B** — 22 места, открытая. От зоны A отделена габионными стенками
  1000×600 (толщина 300 мм принята) по линии разметки в каждом ряду, по 5
  коробов, заполнение — средний камень.

## Дорожные знаки

46 стоек по плану: положение — чёрная точка выноски, щит 700 мм на стойке
3 м, тип щита — по символу (5.19.1/5.19.2, 6.4, 2.4, 2.5, 3.24, 2.1, 3.28).
Ориентация — по ближайшей стрелке движения, щиты двусторонние.

Все параметры — в `data/site.json`, просмотрщик читает их напрямую.

## АБК-1 (здание 1)

Источник — `Office_Building-1.dwg` (AutoCAD 2018, модульное здание турецкого
производства). DWG прочитан LibreDWG → DXF → ezdxf. Взят архитектурный план
(слои PANEL, PENCERE, KAPI, Equipment) и фасад (отметки +0.00 / +2.40 / +3.60).

- Габарит 43,575 × 14,63 м, коридор 2 м, кабинеты 3,5+3,5 м с севера и 2,5+2,5 м с юга.
- Стены — панели 105 мм, высота 2,40 м; парапет до 3,60 м, плоская кровля.
- Окна W3 850 мм (подоконник 1,00, верх 2,07), двери D2 840 мм, WC 620/720 мм.
- Входы AL1 по торцам коридора и AL2 на южном фасаде — крыльца с козырьками.

## АБК-2 (здание 2.1)

- Планировка и мебель — «АБК 2 удлинённый V.2.pdf» (растр): стены найдены по
  двойным линиям, стеклянные перегородки — по одиночным, мебель — по контурам
  (точность ≈ ±0,1 м). Двери кабинетов — по разрывам стен, где разрыва нет —
  по одной в коридорной стене помещения. Входы: торцы по осям 1 и 20, с севера
  у осей 9–10, проход из храма к осям 17–20.
- Оси 12–17 — **храм**: зал на всю ширину, 8 колонн 200×200 по осям 13–16 на
  линиях B и C.
- Конструктив и внешний вид — «Итог1.pdf» (91VVF): сетка 3,1 м, стены 110/100 мм
  до +3,000, карниз +3,450, конёк +4,350 (уклон 0,12), металлофермы с равным
  шагом 3,1 м, прогоны, окна 1000 мм (0,9–2,1 м) по одному на пролёт.
- Ориентация на участке: длинная сторона по пятну 2.1 (север–юг), здание
  развёрнуто на 180° (`placement.rotation_deg = 270`), храм — в южной части.
